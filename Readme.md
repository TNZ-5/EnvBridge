## About The Project

EnvBridge is a powerful tool for managing logs. It is easy to use, and scalable. If you are looking for a solution to collect, analyze, and visualize logs, then EnvBridge is a great option.

It provides a unified view of your logs from multiple sources, so you can easily troubleshoot problems and identify trends. EnvBridge also includes a powerful search engine and analytics features to help you make better decisions about your systems.

## Usage

Here are some specific examples of how you can use EnvBridge:

- **Load Environment Variables**: Ability to load environment variables from `.env` files or specific file paths.
- **Export Variables**: Set environment variables in the current shell or session.
- **Manage Variables**: Add, modify, and delete environment variables programmatically.
- **Configuration File**: Use `.env` files to define variable key-value pairs.
- **Export Variables for External Tools**: Optionally export environment variables for use with other tools or programs.
- **Logging & Debugging**: Log actions and provide debugging information for ease of troubleshooting.

## Technologies Used

- **Go (Golang)**: Programming language used to build the tool.
- **.env Files**: Text-based files to store environment variables in `KEY=VALUE` format.
- **JSON/YAML (Optional)**: For storing configuration data, such as environment settings.
- **CLI Library**: A Go library like `cobra` or `urfave/cli` to help build the command-line interface.
- **dotenv (go-dotenv)**: A Go library for loading environment variables from `.env` files.
- **Logging**: Go’s built-in `log` package or a logging library like `logrus` for better log management.
